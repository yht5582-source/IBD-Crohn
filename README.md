# IBD 發炎性腸道疾病評估與治療決策計算機

這是一個基於 **ECCO (歐洲克隆氏症與潰瘍性大腸炎組織)** 與 **AGA (美國腸胃科學會)** 最新指引所開發的互動式單頁網頁應用程式 (PWA)。本工具將繁瑣的 IBD 疾病活躍度評分系統數位化，旨在協助胃腸科醫師及跨專科團隊快速評估病患狀況，並提供標準化的治療升降階策略。

此工具不僅能輔助臨床醫師決定藥物處方，亦非常適合營養科團隊在規劃 IBD 病患的急性期營養支持（如克隆氏症的專屬腸道營養介入）時，藉由客觀分數快速掌握病患的發炎嚴重度與預後。

## 專案特色

*   **雙系統整合**：單一介面無縫切換 **潰瘍性大腸炎 (UC, Mayo Score)** 與 **克隆氏症 (CD, CDAI)** 兩種截然不同的評估工具。
*   **指引導向決策**：不只計算分數，更直接將結果對應至 ECCO/AGA 建議的「逐步升級 (Step-up)」或「由上而下 (Top-down)」免疫抑制劑與生物製劑治療策略。
*   **純前端架構**：採用 Vue.js 3 進行資料雙向綁定與即時運算。所有數據皆於使用者瀏覽器端處理，完全無伺服器端資料存儲，嚴格保障病患隱私。
*   **PWA 跨平台支援**：結合 Tailwind CSS 的響應式設計與內建 Manifest，支援在手機端直接「加入主畫面」成為獨立 App 運行，方便查房或門診時快速點選。

## 醫學評估邏輯

### 1. 潰瘍性大腸炎 (Ulcerative Colitis) - Mayo Score
系統將自動加總以下 4 項指標（每項 0-3 分）：
*   排便次數異常增加頻率
*   直腸出血與糞便帶血狀態
*   內視鏡黏膜表現 (正常至重度潰瘍)
*   醫師整體評估 (PGA)
*   **結果分級**：臨床緩解 (≤2)、輕度 (3-5)、中度 (6-10)、重度 (>10)。

### 2. 克隆氏症 (Crohn's Disease) - CDAI
考量門診實務限制，將過去 7 天的日記數據簡化為每日平均值輸入，系統將自動套用 CDAI 權重公式：
*   稀軟便次數 (×2)、腹痛程度 (×5)、整體健康狀況 (×7)
*   腸道外併發症 (每項 ×20)
*   使用止瀉劑 (×30)、腹部腫塊 (×10)
*   血球容積比 (Hct) 偏差 (×6) 與體重偏差百分比
*   **結果分級**：臨床緩解 (<150)、輕度 (150-220)、中重度 (221-450)、極重度 (>450)。

## 檔案結構

*   `ibd-calculator.html`: 包含 HTML DOM 結構、Tailwind 工具類別、Vue 互動邏輯以及 PWA 設定的完整單一檔案。
*   `README.md`: 本專案說明文件。

## 部署與使用方式

本應用程式採零相依性 (Zero Dependencies) 設計，部署極為輕量：

1.  **版本控管與託管**：您可以依循過去的開發習慣，直接將此 HTML 檔案新增至您常用的 GitHub 專案庫空間中。
2.  **靜態網頁發布**：在儲存庫設定中開啟 GitHub Pages 功能，將目錄指向該檔案，即可獲得對外公開的 HTTPS 網址。
3.  **行動端安裝**：在手機或平板瀏覽器開啟該網址後，於瀏覽器選單點選「加入主畫面 (Add to Home Screen)」，即可建立帶有專屬 Icon 的桌面捷徑，享受無網址列的全螢幕體驗。

## 聲明與免責條款

本互動網頁僅為臨床與營養照護決策輔助工具 (Clinical Decision Support Tool)。IBD 的實際治療與營養介入計畫極為複雜，需考量病患之年齡、共病症、既往用藥史、腸道狹窄或廔管等結構性病變。本工具產出之結果不應取代主治醫師及多專科照護團隊的最終專業醫療判斷。
