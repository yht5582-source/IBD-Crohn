# IBD 發炎性腸道疾病評估與治療決策計算機

這是一個基於 **ECCO (歐洲克隆氏症與潰瘍性大腸炎組織)** 與 **AGA (美國腸胃科學會)** 最新指引所開發的互動式單頁網頁應用程式 (PWA)。本工具將繁瑣的 IBD 疾病活躍度評分系統數位化，旨在協助胃腸科醫師及跨專科團隊快速評估病患狀況，並提供標準化的治療升降階策略。

此工具不僅能輔助臨床醫師決定藥物處方，亦非常適合營養科團隊在規劃 IBD 病患的急性期營養支持（如克隆氏症的專屬腸道營養介入）時，藉由客觀分數快速掌握病患的發炎嚴重度與預後。

## 專案特色

*   **雙系統整合**：單一介面無縫切換 **潰瘍性大腸炎 (UC, Mayo Score)** 與 **克隆氏症 (CD, CDAI)** 兩種截然不同的評估工具。
*   **指引導向決策**：不只計算分數，更直接將結果對應至 ECCO/AGA 建議的「逐步升級 (Step-up)」或「由上而下 (Top-down)」免疫抑制劑與生物製劑治療策略。
*   **純前端架構**：採用 Vue.js 3 進行資料雙向綁定與即時運算。所有數據皆於使用者瀏覽器端處理，完全無伺服器端資料存儲，嚴格保障病患隱私。
*   **PWA 跨平台支援**：結合 Tailwind CSS 的響應式設計與內建 Manifest，支援在手機端直接「加入主畫面」成為獨立 App 運行，方便查房或門診時快速點選。

## 醫學評估邏輯 (v2.0)

### 1. 潰瘍性大腸炎 (UC)
*   **Mayo Score (0–12)**：排便次數、直腸出血、內視鏡、PGA 各 0–3。緩解 = 總分 ≤2 且無單項 >1；輕度 3–5、中度 6–10、重度 11–12。
*   **Partial Mayo (0–9)**：尚無內視鏡時自動切換（Lewis 2008）：緩解 ≤1、輕度 2–4、中度 5–6、重度 7–9。
*   **Truelove & Witts**：血便 ≥6 次/日 + 心跳 >90、體溫 >37.8°C、Hb <10.5、ESR >30 或 CRP >30 任一 → 急性重度 UC，優先於 Mayo，給住院 / 靜脈類固醇 / 第 3 天評估 / 救援路徑。
*   治療依 Montreal 範圍 (E1–E3) 與嚴重度：輕度以 5-ASA 為主；中重度依 AGA 2024 早期進階治療。

### 2. 克隆氏症 (CD)
*   **CDAI**（Best 1976，輸入 7 天每日平均，自動 ×7）：稀便 ×2、腹痛 (0–3) ×5、整體感受 (0–4) ×7、6 類併發症各 ×20、止瀉藥 ×30、腹部腫塊 (0/2/5) ×10、(基準 Hct − Hct) ×6（負值以 0 計）、100 × (1 − 體重/標準體重)（最低 −10）。標準體重可直接輸入或依身高以 BMI 22 估算。分級：<150 緩解、150–219 輕度、220–450 中重度、>450 重度。
*   **Harvey-Bradshaw Index**：門診簡易版；<5 緩解、5–7 輕度、8–16 中重度、>16 重度。
*   Montreal 位置 / 行為與高風險預後因子：輕症但具高風險者依中重度處理；AGA 2025 (Rec 3/4/9/15) 進階治療選擇；疑似膿瘍、狹窄、肛門廔管另有警示。
*   ESPEN 2023 營養照護建議（EEN、PN 適應症、微量營養素）。

## 檔案結構

*   `index.html`：單一頁面（Vue 3 + Tailwind CDN）。計算引擎 `IBD` 位於 `/*ENGINE-START*/ … /*ENGINE-END*/` 之間。
*   `tests.cjs`：引擎測試，執行 `node tests.cjs`。
*   `manifest.webmanifest`、`icon.svg`：加入主畫面用。
*   `README.md`：本說明。

## v2.0 修正紀錄 (2026-10-25)

*   CDAI 整體感受補上 4 分（極差）；口瘡性潰瘍併入皮膚類、補上「其他廔管」，符合原始 6 類。
*   清空 Hct 欄位時原本會被當成 0 而加 282 分 → 改為不計分並提示。
*   體重偏差由 5% 級距選單改為實際體重 / 標準體重計算，含超重 −10 下限。
*   UC 緩解定義改為「≤2 且無單項 >1」；新增 Partial Mayo、Truelove & Witts。
*   重度 UC 不再只看 Mayo >10 就要求住院，改以 Truelove & Witts 判定 ASUC。
*   治療建議更新至 AGA 2024 UC / AGA 2025 CD / ECCO / ACG 2025；新增進階治療前篩檢（TB、HBV、NUDT15）。
*   PWA manifest 由 blob URL（瀏覽器不支援安裝）改為實體檔；固定 Vue / Tailwind 版本；移除禁止縮放；避免載入時閃現 {{ }}。

## 聲明與免責條款

本互動網頁僅為臨床與營養照護決策輔助工具 (Clinical Decision Support Tool)。IBD 的實際治療與營養介入計畫極為複雜，需考量病患之年齡、共病症、既往用藥史、腸道狹窄或廔管等結構性病變。本工具產出之結果不應取代主治醫師及多專科照護團隊的最終專業醫療判斷。
